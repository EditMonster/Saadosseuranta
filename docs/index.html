Aihealue

Kansallinen lainsäädäntö

Kaikki valmisteilla ja eduskunnassa olevat hallituksen esitykset (Hankeikkuna + eduskunnan avoin data). Lausuttavissa olevat nousevat kärkeen. Napsauta riviä, niin tapauksen aikajana avautuu.

Euroopan unioni

Tavallisen lainsäätämisjärjestyksen menettelyt (Euroopan parlamentin avoin data + Cellar), joiden soveltaminen tai täytäntöönpano on vielä kesken.

Maaliin menneet

Hyväksytyt ja voimassa olevat säädökset, joista ei ole enää lausuttavaa. Napsauta riviä nähdäksesi tapauksen aikajanan.
