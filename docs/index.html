            Kansiot

            Kansioon voi viedä säädöksiä, EU-menettelyjä, kilpailutuksia ja yrityskauppoja; sama kohde voi olla useassa kansiossa. Kansion valinta yläpalkista rajaa kaikki näkymät – myös Tilannekuvan – kansion kohteisiin. Omat kansiot tallentuvat tähän selaimeen (siirtolinkki Seurannassa-paneelista). Tiimikansiot ovat jaettuja: kaikki näkevät ne, ja jokaisella on oma kalenterisyöte (Outlook, Google, webcal) sekä Teams-ilmoitussyöte. Sisältö voi olla kiinteitä kohteita tai sääntöjä (aihealue, toimiala, hankintayksikkö, hakusana, yrityskaupan osapuoli), jolloin kansio toimii tiimin seurantaprofiilina ja täyttyy itsestään. Muutokset tehdään tästä sivusta tiimin avaimella (Jakamisen asetukset) ja ne toteutuvat automaattisesti noin minuutissa.

            Jakamisen asetukset

            Tiimikansioiden muutokset (kohteen lisäys, uusi kansio, säännöt) tehdään suoraan tästä sivusta. Sivu tarvitsee siihen tiimin avaimen, jonka saat tiimisi ylläpitäjältä – esimerkiksi Teamsin kautta. Avain tallentuu vain tähän selaimeen. Muutos toteutuu automaattisesti noin minuutissa, ja sivu kertoo, kun se on valmis.

            Ylläpitäjälle: näin teet tiimin avaimen (kerran)

            Avain on GitHubin fine-grained personal access token, joka saa tehdä tässä repossa vain yhden asian: avata muutospyyntöjä (issues). Se ei pääse koodiin eikä aineistoon. Luo avain GitHubissa → Repository access: Only select repositories → valitse tämä repo → Permissions → Issues: Read and write (Metadata tulee automaattisesti) → voimassaolo enintään vuosi. Jaa avain tiimille Teamsissä. Jos avain vuotaa, poista se GitHubista – vahinko rajoittuu turhiin pyyntöihin, jotka näkyvät repon issueissa. Kansiot ovat julkisia siinä missä repokin: ei asiakas- tai toimeksiantotietoa.
